# 问题定位与调试方法

> 张鑫旭式排查：不猜，用工具和机制去"证明"。

## 1. 最小化复现

- 把问题抽成最小 demo（一个 HTML + 一段 CSS），去掉业务无关代码
- 能稳定复现的 bug 已经解决一半
- 若最小化后问题消失 → 干扰项在别处，逐步加回定位

## 2. 二分排除法

- 怀疑 CSS 某段冲突？注释掉一半，看问题在不在
- 反复二分，快速锁定到具体规则

## 3. 开发者工具三板斧

### Elements 面板
- **Computed**：看最终生效值（含来源文件/行号），确认是不是被覆盖
- 点击属性旁边的箭头跳到定义处
- **Styles** 面板里被划掉的声明 = 被更高优先级覆盖，或无效值

### 强制状态 / 选择器检查
- 用 `:hov` 触发 hover/focus
- 在 Elements 里直接改样式实时预览

### Layout 相关
- 选中元素看盒模型高亮（content/padding/border/margin）
- 用 `outline` 或背景色标记疑似元素，肉眼确认几何边界

### Console
- `getComputedStyle(el).propName` 读取计算值
- 检查是否有资源 404、CSS 解析错误

### Network
- 确认 CSS 文件是否加载成功（200）、是否有缓存问题
- 背景图/字体是否请求成功

## 4. 定位问题归类表

| 症状 | 先怀疑的机制 | 参考 |
|------|------------|------|
| 样式没生效 | 优先级 / 继承 / 选择器未命中 / 值无效 | css-mechanisms §1 |
| z-index 无效 | 层叠上下文 | css-mechanisms §1 |
| 高度塌陷 / 撑不开 | float、BFC | css-mechanisms §2 |
| 外边距"穿透" | margin 合并 | css-mechanisms §3 |
| 定位偏移不对 | 包含块 | css-mechanisms §4 |
| 上下留缝 / 对不齐 | 基线、vertical-align | css-mechanisms §5 |
| 宽高算不对 | 尺寸约束、box-sizing、百分比 | css-mechanisms §6 |
| fixed/sticky 异常 | 包含块 / 滚动容器 | css-mechanisms §4、§7 |

## 5. 排除干扰的检查清单

- [ ] 是不是拼写错误 / 属性名或值写错（CSS 不报错，静默忽略）
- [ ] 选择器是否真的命中目标元素（用 DevTools 验证）
- [ ] 是不是被 `!important` 或更高优先级覆盖
- [ ] 是不是继承了不该继承的值
- [ ] 是不是该属性根本不支持该元素/该浏览器
- [ ] 是不是缓存导致旧 CSS 未更新（硬刷新 Ctrl+F5）
- [ ] 是不是有语法错误导致整条规则被丢弃（检查大括号/分号）

## 6. 记录与验证

- 修完用最小 demo 复测，确认根因，而非"碰巧好了"
- 能说清楚「为什么」才叫修好；否则 bug 还会换个马甲回来
